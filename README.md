# Проект "Турельница" (Turret_2)
Проект "Турельница". 2Д-игра в жанре tower-defence. Распространяется полностью бесплатно.
___
## Общая информация
Идейные вдохновители "Турельницы": "Mindustry", "Yorg.io", "Factorio". 
Графика игры базируется на SDL3 и OpenGL 4.6.
___
## Минимальные системные требования
1) Процессор Intel Core i3 / AMD FX с тактовой частотой 2.5 ГГц и более (или эквивалентный с поддержкой инструкций SSE4.2).
2) 4 ГБ ОЗУ.
3) Видеокарта или встроенное графическое ядро с поддержкой OpenGL 4.6: (NVIDIA GeForce GTX 750 Ti / GTX 950, AMD Radeon RX 360, Intel HD 530) или новее.
4) Свободное место на диске 25 МБ для самой игры, 512 МБ для сохранений. 
5) 64-разрядная ОС: Windows 10/11, Linux Ubuntu latest(могут быть трудности с запуском на других дистрибутивах Linux, сообщите при обнаружении ошибок).
___
## Библиотеки
Все используемые библиотеки лежат в папке "libs" в готовом собранном виде. Лицензии всех используемых библиотек прилагаются "libs/licenses".
Решение напрямую разместить библиотеки в репозитории проекта принято в целях повышения надёжности и простоты сборки проекта.
___
## Взаимодействие и помощь
Нужно доработать инструкции по сборке проекта. Нужно создать понятную для любого новичка инструкцию с картинками. 

### Как собрать проект у себя?
#### Windows (MSVC, Visual Studio 2026)
1) Выбрать папку проекта, нажать "открыть с помощью Visual Studio". Или открыть Visual Studio и в Visual Studio открыть папку проекта.
2) Visual Studio автоматически загрузит "CMakePresets.json" и предложит выбор конфигурации сборки. Для сборки игры со всеми оптимизациями и без интеграционных тестов выберите "release". Нажмите на кнопку сборки(зелёный треугольник с подписью "Turret_2.exe").
3) В папку с собранной игрой ("build/release") скопируйте папку "res" и ".dll"-файлы из "libs/MSVC_dll".
4) Проект собран. Можно запускать исполняемый файл "Turret_2.exe". Всё уже должно работать.
#### Linux (GCC, CMake)
1) Наведите курсор мышки на пустое место внутри папки. Нажмите правую кнопку мыши.
2) В появившемся меню выберите "открыть в терминале".
3) Введите в терминале "cmake .". Команды терминала нужно вводить без кавычек. Дождитесь результата выполнения команды.
4) Введите в терминале "cmake --build .". Дождитесь результата выполнения команды.
5) В папку "build" скопируйте папку "res" и ".so"-файлы из "libs/GCC_so".
6) Проект собран. Можно запускать исполняемый файл "Turret_2". Всё уже должно работать.
